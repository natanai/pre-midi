# Third-party notices

Pre-midi's application code and original procedural synthesizer presets do not bundle
external runtime libraries or copied instrument plugin code.

The optional recorded sample pack distributed in the static Pages artifact
contains **CC0 1.0 Universal** recordings from:

- Meta Open Sound: Meta Piano, Nylon Guitar and Steel Guitar
  https://github.com/facebookincubator/Meta-open-sound
- Stargate Sample Pack: acoustic/electronic percussion one-shots
  https://github.com/stargatedaw/stargate-sample-pack
- Versilian Community Sample Library: recorder and ball whistle
  https://github.com/sgossner/VCSL

License: https://creativecommons.org/publicdomain/zero/1.0/

The precise source file paths, pinned source revisions and checksums are
in samples.js. A curated per-source summary is in docs/sample-sources.md.
These assets are CC0, so attribution is not required, but it is preserved
here as part of the engine's authoring provenance.

An author can also import their own WAV, OGG or MP3 samples. Imported audio
is included in their .premidi composition file, so its rights depend on the
author's chosen recording. Pre-midi does not claim to license those uploads.
