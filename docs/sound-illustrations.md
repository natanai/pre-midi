## Current illustration completion pass (2026-11-06)

The user's current request supersedes the November 5 feature freeze below: finish waveform illustrations, repair expanded modules, calm incidental hover, prefer related X/Y controls, make movement smoothing visible, and preserve position/focus after releasing the pulse amount dial. This pass changes the shared renderer used by Beat, freeform, samples and vocals; it does not fork the Inspector or change DSP/project formats.

- **Filter and distortion belong to one module.** The original distortion knob remains, beside brightness/resonance. A named waveform page has a logarithmic brightness X axis and distortion Y axis, with before/after traces of an explicitly labeled 220 Hz reference tone. It uses the actual biquad magnitude **and phase**, shared drive lookup/interpolation, zero-drive bypass, and playback's level compensation. Input/output share the same displayed amplitude scale. The frequency-response view and synth sweep/noise view remain available. Arbitrary recorded PCM is never replaced by a fictional measured waveform; the measured Sound scope is still independent.
- **Movement smoothing now shapes the plotted signal**, rather than moving only a handle. Every source (LFO, envelope, touch and key tracking) uses playback's source/polarity functions and zero-initialized one-pole recurrence at 48 kHz. Dashed raw and colored smoothed traces show lag/attenuation; non-LFO overviews pair smoothing with depth, and LFO details offer both speed/depth and smoothing/depth. All movement dials preview their graph while dragging.
- **Expanded modules keep readable text.** SVG scales only the signal paths; captions are normal-sized HTML overlays. A separate graph toolbar prevents page controls from covering captions. The overlay is centered and bounded at 1040 px, accounts for viewport scrollbars, and places oscillator controls in adjacent columns when space permits.
- **Incidental hovering stays quiet.** Graph/knob pointer crossings no longer trigger linked highlights in Sound or per-note graphs. Deliberate focus/adjustment retains a subtle stroke and accessible focus indicators, without glow or enlarged points. Point explanations appear after a short dwell or immediately for keyboard focus.
- **Dial commits preserve the view.** The shared dial captures its canonical field path and scroll ancestors before the owning editor rebuilds, restores the equivalent control with `preventScroll`, and restores inspector/expanded-panel scroll offsets. This covers pulse amount and the other Sound dials through the same implementation.

**Verification:** `npm run check` passes **586 tests**. Browser regressions retain the full control inventory, pointer cancellation, atomic dual-axis history, Beat/Freeform synchronization, sampled and vocal controls. The new regression exercises actual brightness/distortion drag + one Undo, live smoothing preview, pulse release with a genuinely replaced dial, ordinary/expanded scroll preservation, and expanded label/bounds checks at desktop and 780 px inspector widths. The real Web Audio IIR comparison observes maximum errors below **0.000003** for velocity-step and negative-depth LFO fixtures. Full CI/publication references are recorded with the delivery PR.

**Intentional dimensional limits:** individual sample envelope timing endpoints and MIDI-root mapping retain their natural time/keyboard axis; harmonic painting already uses partial index × amplitude. A bypassed vocal filter cannot supply an audible brightness axis until re-enabled, so its distortion waveform identifies `filter off` and edits drive alone. Do not invent audio parameters just to force a second axis.

The existing Windows ZIP is not rebuilt by this pass; physical Windows 11 and Safari/Home Screen acceptance remain separate from browser evidence. ## Approved product requirements / non-negotiables

1. Each applicable existing knob/selector has an intelligible educational illustration that can **directly change its parameter**, not merely highlight or navigate to the knob. Retain control and diagram options in parallel. Explicitly document any physical/semantic reason for a genuinely nonvisual exception.
2. Prefer genuine simultaneous X/Y control (four physical movement directions) when two related parameters make educational sense. Do not invent a parameter or draw a false relationship just to obtain two axes. Spectral painting spans partial index on X and amplitude on Y; a MIDI root is naturally a horizontal keyboard position.
3. Graphs visibly respond when conventional controls change, and conventional controls refresh when the illustration changes. Drag, keyboard (including shift precision), categorical toggles, empty-space navigation, zoom, A/B measurement and focus preservation must be checked. Related axes should commit as **one edit / one undo step**.
4. Present honest units and musical predictions; explicitly distinguish calculated explanatory curves from actual measured PCM scope. Test numerical ranges, log scales, limiting behavior, inactive parent effects and browser/native parity.
5. An edit must never silently write a different owning object. Freeform note cutoff versus Beat/Instrument cutoff can reuse the illustration while preserving distinct automation targets.
