# pre-midi 0.14.1-preview.37 Windows portable

## Changes since preview.36

- Synth noise now has white, pink and brown colors and a cutoff. The noise spectrum shows the selected color and bandwidth. Level and decay still shape the noise over time.
- Distortion offers soft clip, hard clip and wavefold with input trim and compensated wet level. The main stage and added instances can have different settings. The same processing is available for synths, sampled Sounds and vocals.
- Vocal Clips and one-shot samples have editable fade-in and fade-out handles on the source waveform. The fades are stored in playback seconds and follow the crop, playback direction and stretch.

## Install and test

Extract the whole ZIP to a writable folder and open pre-midi.exe. For a manual update, close the app and replace the application files. Keep your data/, projects/ and exports/ folders.

Try playing a Song, pausing, editing a Sound, seeking and resuming, then press Stop while playback is preparing. Try the new distortion and noise settings in the Sound Inspector. Test the fade handles on a cropped vocal Clip or one-shot sample, then save, reopen and export to WAV.

This is a manual Windows 11 x64 portable preview. Physical audio and microphone testing, extended automation and routing, pitch correction and the wider release roadmap are still open.
