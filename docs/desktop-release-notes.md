pre-midi 0.14.1-preview.14 includes a transactional Windows portable self-updater, but automatic installation is available only in builds containing an update-signing public key and with a matching signed release ZIP. Unsigned portable ZIPs remain downloadable and use manual folder-preserving updates: close the app, back up the folder and replace the application files, retaining data/, projects/ and exports/. No registry changes or installer are required. Signed editions can verify the version-bound signature, close cleanly, replace application files from a separate helper and roll back when installation or startup fails.

This release also incorporates the web studio changes since preview.13, including piano-roll interaction, sound selection, QWERTY performance and phone-studio progress. Native audio remains C++17/miniaudio; direct physical Windows 11 audio-device latency, dropouts and recovery need hardware testing. Publishing an unsigned ZIP for manual updating does not require any signing configuration; the updater refuses unsigned automatic installations. Stable release publication remains manually qualification-gated.
