pre-midi 0.14.1-preview.14 adds signed transactional Windows portable self-updates. Open Settings > updates and select preview or stable. pre-midi verifies the version-bound signature of the official GitHub ZIP, closes cleanly, replaces application files from a separate helper, then reopens and checks readiness. If replacement or startup fails, it restores the previous executable and application files. Existing data/, projects/ and exports/ are never overwritten. Older unsigned previews require one manual upgrade after update signing is configured.

This release also incorporates the web studio changes since preview.13, including piano-roll interaction, sound selection, QWERTY performance and phone-studio progress. Native audio remains C++17/miniaudio; direct physical Windows 11 audio-device latency, dropouts and recovery need hardware testing. Signed package publishing is blocked until the updater key and GitHub signing variable are provisioned. Stable release publication remains manually qualification-gated.
